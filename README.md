## Working With These Notes

Use the challenge notes as personal lab records, not as universal procedures. Verify commands and findings against the current target, and only test systems you own or are explicitly authorized to assess. Some notes may contain lab-specific IP addresses, credentials, flags, or other sensitive data; review and redact them before sharing or publishing this repository.
